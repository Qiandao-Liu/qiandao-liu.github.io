  4. 04

    Firmware and PC connection

    Firmware source · ZIP ↓ HEX ↓ BIN ↓

    4A Flash the STM32

    WUDI keeps the same STM32F042K6T6 and dual-ADS1256 modules as DexUMI; only the carrier mainboard is replaced.

    1. Install OpenOCD: sudo apt-get install openocd.
    2. With target power off, connect ST-Link V2: VTref → 3.3 V, GND → GND, SWDIO → PA13, and SWCLK → PA14. NRST is recommended.
    3. Power the board, place WUDI_Encoder16.hex in the current directory, and run:
    openocd -f interface/stlink-v2.cfg \
  -f target/stm32f0x.cfg \
  -c "program WUDI_Encoder16.hex verify reset exit"

    4B Connect the board to the PC

    1. Insert the STM32 core board in the top socket and both ADS1256 modules in the lower sockets. Confirm orientation before applying power.
    2. Connect regulated 5.0 V / 1.0 A through the XT30 female lead, then turn on the board switch.
    3. Connect a 3.3 V USB-to-TTL adapter: board PB6 / USART1_TX → adapter RX, board PB7 / USART1_RX → adapter TX, and GND → GND.
    4. Open the serial port at 921600 baud, 8N1. WUDI firmware sends all sixteen ADS1256 inputs in fixed 72-byte packets.

    Do not use a 5 V UART signal. Disconnect ST-Link after flashing unless the shared-ground debug setup has been reviewed.
